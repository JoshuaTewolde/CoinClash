# CoinClash

Friends-only, turn-based games for sats, built on the Breez SDK (Spark). Work in progress for
Hack The Nest 2026.

- Spec: [`docs/SPEC.md`](docs/SPEC.md)
- Contributor and agent notes: [`CLAUDE.md`](CLAUDE.md)

```sh
pnpm install
cp .env.example .env   # fill in values
pnpm dev               # web on :5173, server on :8787
pnpm test
```
